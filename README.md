## 什么情况下这笔钱花得值

磁盘分析这类工具省的是找文件的时间，它不生产空间，只告诉你空间去哪了。系统自带的面板能显示“文稿”“系统数据”各占多少，但常常把一大堆东西糊在一起，你点进去也不知道该删哪个。命令行能看到每一层目录的大小，代价是一层层翻，一个深目录翻下来十分钟就过去了。

真正需要付费工具的，是这几类人。

硬盘长期处于八分满以上，隔三差五要清一次。这种人用得最频繁，买断价摊到每次使用几乎可以忽略。

手上不止一块盘。外接硬盘、移动固态、网络盘都算，很多免费工具只扫系统盘，或者扫外接盘时慢到不能用。买之前值得确认一下它认不认你的盘，这件事在页面的功能说明里一般会写。

经常装软件、试软件、删软件。卸载残留会一点点吃掉空间，而且藏在几十层深的目录里，靠肉眼找基本不可能。

想先看清再动手。分析工具通常是只读的，先给出一个按大小排序的目录树，你自己决定删什么。这比那些“一键释放 XX GB”的清理工具安全，后者你根本不知道它删了什么。

反过来算一笔账。如果一个月用一次，买断价除以十二，你可能觉得还好；如果一年用两次，那这笔钱不如省下来，加一块移动硬盘更实在。

## 哪些人不用买

只打算清一次系统盘的人，不用买。装一次、扫一次、删一次，之后卸载，这种情况下免费工具完全够用。付费工具的价值在反复使用，不在一次性。

系统盘报警主要是因为缓存和旧安装包的人，也不用买。这类问题用系统自带的存储管理清一遍就解决了，不需要分析器告诉你哪个文件夹大。

习惯用命令行的人，写个 `du -sh *` 排序一下就能看到结果，工具带来的提升有限。

预算真的紧张的人。这类小工具不是刚需品，它解决的是效率问题，不是“没有它就没法用”的问题。等到你真的被空间问题烦到每周都要处理一次，再买也不迟。

**数码荔枝是官方吗？**
不是。它是卖正版授权的商店，Disk Space Analyzer 的开发商另有其人。授权是真的，但软件本身的更新和技术支持要找开发商。

**现在有优惠码吗？**
没有可核实的公开码。历史活动码都在结算页填，都带截止日期，过了就失效。

**买断还是订阅？**
以商品页标注为准。页面上写“一次性”就是买断，写“/年”就是订阅，这是最直接的判断方法，不用猜。

虚拟授权类商品的退款条款各家不同，我没查到这款的具体政策。下单前直接问客服，比事后争议省事。

**能装几台电脑？**
看商品页“授权类型”那一段，那里会写明可激活的设备数量。
